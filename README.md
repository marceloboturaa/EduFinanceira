## 🧾 Sinopse

**EduFinanceira** é um projeto educacional criado para apresentar e divulgar os trabalhos desenvolvidos pelos estudantes na disciplina de **Educação Financeira**.

O site funciona como uma **exposição digital**, reunindo vídeos, apresentações, pesquisas, tabelas informativas e materiais de apoio produzidos durante as atividades pedagógicas.

A proposta é valorizar a produção dos alunos e permitir que os conteúdos estudados em sala de aula sejam explorados de forma organizada, interativa e acessível em diferentes dispositivos.
